# Aurê Estética · Landing page conceitual

Projeto de portfólio: landing page imersiva para clínicas de estética.
Marca, pessoas, endereço e imagens são fictícios.

**Destaques**
- Abertura animada com monograma desenhado em dourado
- Foto fixa em arco enquanto a história da profissional rola ao lado
- Veio dourado que se desenha conforme a rolagem
- Seção de tratamentos com rolagem horizontal e seleção que monta a mensagem de WhatsApp
- Comparador de antes e depois arrastável
- Painel "Personalizar" para trocar paleta e tipografia ao vivo
- Responsivo e com respeito a "reduzir movimento"

Feito com HTML, CSS e JavaScript puros (Lenis para rolagem suave).

Design e desenvolvimento: Murilo
